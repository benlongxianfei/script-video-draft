# 踩坑速查

## 生成

| 现象 | 真因 | 处理 |
|---|---|---|
| `429 video generation rate limit exceeded: allows 1 requests per 1 minute(s)` | 账号级视频限速 | 相邻提交 ≥65s；429 读 `Retry-After`，没有就等 70s |
| `429 video status query rate limit exceeded` | 查询也有独立限流 | 轮询间隔 10s（别用 5s） |
| `400 num_frames ... must be 8n+1` | 帧数不合规 | 65 / 121 / 241 |
| `400 num_frames 265 exceeds maximum 241 for 1080p` | 1080p 帧数上限 241 | 长句用 241 帧，不要 265 |
| 图片发糊 | 16:9 生图上限 1312×736 | 别加大请求尺寸；超分后再图生视频，或直接图生视频出 1920×1088 |
| `000201 Resource not found` | `api.agnes-ai.com` 是网页域名 | 用 `api.agnes-ai.cn` |
| 下载 0 字节 | 输出域名需代理（老域名） | 新域名 `cos-platform-outputs.agnes-ai.cn` 可直连 |
| `E2BIG` / arguments too long | 5MB data URL 当命令行参数 | 脚本内直接 fetch，不要走 CLI 参数 |

## 配音

| 现象 | 真因 | 处理 |
|---|---|---|
| `resource ID is mismatched with speaker related resource` | 音色与资源 ID 不匹配 | 预置音色配 `seed-tts-2.0`，克隆音色配 `seed-icl-2.0` |
| 401 | app_id / token 不对或过期 | 重新在控制台取 |
| 音频 <1000 字节 | 合成失败 | 视为错误重试 |
| 听感"语速太慢" | 句间停顿 150~240ms | 压缩停顿到 60ms，**不要 atempo** |
| 某一句明显读太快 | 无逗号的超长句 | 只对这一句轻微放慢后重拼 |
| 全篇错位十几秒 | 时间轴被二次缩放 | 每次从原始时间轴算一次系数，缩放后校验 Σ句 |

## 草稿

| 现象 | 真因 | 处理 |
|---|---|---|
| 字幕出现单字（"生"独占一条） | 硬切逻辑 `text[:max_chars]` | 用按标点切 + 合并的算法；交付前断言单字条目 = 0 |
| 字间距/位置和 UI 对不上 | 剪映 JSON 与 UI 不是 1:1 | 字间距 ×0.05、行间距 ×0.02、Y ÷ 画布高 |
| 播放器在段边界卡停 | concat 后 PTS 乱序（ffmpeg 直出时） | `setpts=N/(30*TB)` + `-bf 0` + `-movflags +faststart` |
| 改完草稿"没有任何改变" | clip 缓存复用 / 替换 key 用错 | clip 文件名带素材指纹；显式段→素材映射 |
| 画面重复 | 段→素材按比例映射 | 显式映射 + 唯一性断言 |
| 草稿读不出字幕 | 剪映 6+ 加密 | 不要尝试解密，改成新建草稿 |
| 重建失败"文件被占用" | 剪映正打开该草稿 | 换新目录 + 新草稿名 |

## 验收

| 现象 | 真因 | 处理 |
|---|---|---|
| 静帧正常但成片双头 | 运动帧结构崩塌 | 抽 0.8 / 2.5 / 4.2s 三帧复核，单镜重做 |
| 视觉模型说"分身"但设计上就是多角色 | 模型误报 | 把"本镜应为 N 个角色"写进问题里复核 |
| 视觉检查接口 401/402/404 | 用了中转站 / 额度耗尽 | 换官方 key，或退化为人工指认镜号 |
| 送检连接重置 | 图太大 | 先缩到 768px / 40KB |
