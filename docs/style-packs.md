# 画风包：只改提示词骨架，不动流程

换画风时**不要改脚本**。改的永远是两处：正向的画风描述 + 负向的禁止项。

## 通用骨架

```
<画风描述>，<纸张/材质/颗粒>，<色调与光线>，
<主体锚点：完整的外貌/物种描述>，<单个主体 + 一个动作>，
<构图：景别 + 主体位置>，画面铺满整张画布；
负向：<禁止项列表>
```

> **画幅硬要求（四套风格通用）**：一律 `画面铺满整张画布`，负向常驻
> `不要黑边，不要上下黑色遮幅，不要电影宽银幕边框`。
> 电影遮幅黑边在剪映里会变成实体黑条，压主体、顶字幕，后期还得裁掉重放大 —— 不要。
> 想要电影感就压暗四角、加强轮廓光、降背景饱和度。

## 1. 黑白蚀刻版画（默认）

**正向**
```
黑白蚀刻版画风，细密平行排线，纸张纹理轻微噪点，暗角，
主体：<锚点>，单人/单主体，一个主要动作，
中景，主体居中偏左，画面干净，无文字，无Logo，无边框
```

**负向**
```
不要彩色，不要水彩，不要3D渲染，不要边框，不要相框，不要白边，不要黑边，
不要重影，不要分身，不要第二个人物，不要文字水印
```

## 2. 低饱和扁平拼贴 / 条漫

**正向**
```
低饱和扁平插画，2D矢量块面，硬边阴影，纸片剪贴质感，米灰背景 + 少量强调色，
主体：<锚点>，正面或侧 3/4 视角，简洁几何构图，画面干净，无文字
```

**负向**
```
不要写实质感，不要渐变立体，不要照片，不要景深虚化，不要边框，不要黑边，不要上下黑色遮幅，不要重影，不要文字
```

## 3. 暖墨轻彩火柴人

**正向**
```
手绘墨线火柴人，圆头极简线条，水彩轻染淡彩，暖白纸张，轻微笔触抖动，
主体：<圆形头部 + 简笔身体 + 一个动作>，大量留白，画面干净，无文字
```

**负向**
```
不要写实人脸，不要厚涂，不要3D，不要浓艳配色，不要边框，不要黑边，不要上下黑色遮幅，不要重影，不要文字
```

## 4. 2D 动画概念·拟人动物绘本

现代 2D 动画电影的概念设定图气质：角色有清晰勾线，背景是**比角色更写实**的绘画环境，
暖色斜射光在角色边缘打出轮廓光，森林绿与夕阳橙做互补对比。
适合动物拟人主角、寓言/成长类叙事。

**正向**
```
2D动画电影概念图，现代数字绘本插画，深色细勾线描边，线条粗细有变化，
cel 与柔笔刷混合上色，毛发表面有方向性笔触，
暖色斜射光配冷色阴影，角色边缘有轮廓光，
背景为半写实绘画环境，明显景深虚化，森林绿与暖橙夕阳互补色，
主体：<锚点>，人形站姿，全身，主体居中偏左，画面铺满整张画布，无文字，无Logo
```

**负向**
```
不要3D渲染，不要塑料质感，不要厚涂油画，不要纯平涂无体积，不要写实真动物，
不要日系赛璐璐大眼，不要边框，不要相框，不要白边，不要黑边，不要上下黑色遮幅，
不要电影宽银幕边框，不要重影，不要第二个主体，不要文字水印
```

**锚点怎么写**

这套风格的辨识度一半来自"角色画得比背景低写实"，所以锚点要把**物种级细节 + 人类服饰**绑在一起写：

```
拟人化赤狐，橙红毛发白色胸腹，尾尖白色，穿深绿马甲，戴黑色手套，人形站姿
拟人化灰兔，灰白毛发粉色耳内，戴蓝围巾，人形站姿
```

- 必须点明"拟人化 / 人形站姿"，否则会出成四脚真动物
- 服饰要具体（马甲/围巾/手套），这是这套风格的记忆点，也是补"角色性格"的最省力手段
- 同一角色复用同一段锚点，只加状态后缀（"提着一盏灯" / "回头看"）

**这套最容易翻车的三处**

| 现象 | 原因 | 改法 |
|---|---|---|
| 出成 3D / 塑料感 | "绘本""动画"被理解成 CG | 负向必须写"不要3D渲染，不要塑料质感"，正向保留"深色细勾线描边" |
| 背景和角色一样平 | 没说背景更写实 | 显式写"背景为半写实绘画环境，比角色更写实，明显景深虚化" |
| 出成真动物 | 缺"拟人化" | 锚点里写死"拟人化 + 人形站姿 + 服饰" |

**画幅：必须满画布，不要电影遮幅**

这类风格的素材库里常见 2.35:1 电影遮幅（上下黑边），但**剪映工程里绝对不能要**：
黑边会变成画面里的实体黑色条，压住主体、顶住字幕，后期还得裁掉再放大，白丢画面上下各 10%。

所以：

- 正向固定写 `画面铺满整张画布`，**不要**写"2.35:1"、"电影画幅"、"宽银幕"
- 负向常驻 `不要黑边，不要上下黑色遮幅，不要电影宽银幕边框`
- 想要"电影感"用别的手段：压暗四角（暗角）、加强轮廓光、降低背景饱和度 —— 都比加黑边安全

**只写"不要黑边"拦不住（实测）**

2026-10-28 用四套风格各出 2 张，负向都写了"不要黑边"，仍有两张翻车：

| 表现 | 原因 | 改法 |
|---|---|---|
| 上下纯黑条（letterbox） | 火柴人那套的"大量留白"被理解成"纸居中 + 黑底" | 正向加 `暖白纸张铺满整个画面`，负向加 `不要上下黑色遮幅` |
| 左右纯黑竖边（pillarbox） | 模型把"电影感"补成宽银幕 | 负向加 `不要左右黑色竖边，不要letterbox，不要pillarbox，不要留黑边填充` |

结论：**负向要把四个方向都点名**，只写一个"不要黑边"模型会漏。

**出图后怎么快速验**（不用肉眼逐张看）

```bash
# 裁四边各 3% 条带，压成 1×1 灰度，值 < 3 基本就是纯黑边
for f in *.png; do
  for spec in "iw:ih*0.03:0:0" "iw:ih*0.03:0:ih*0.97" "iw*0.03:ih:0:0" "iw*0.03:ih:iw*0.97"; do
    ffmpeg -v error -i "$f" -vf "crop=${spec},scale=1:1" -pix_fmt gray -f rawvideo - 2>/dev/null | od -An -tu1
  done | tr '\n' ' '; echo " <- $f"
done
```

## 主体锚点怎么写

- **人**：年龄段 + 发型发色 + 脸型 + 五官克制程度 + 服装 + 体态（同一角色全片复用同一段文字）
- **动物**：物种 + 毛色/花纹 + 体态特征 + 风格化程度（"灰壳小蜗牛，壳身灰旧带几道裂纹，细长触角"）
- **同一角色多状态**：同一锚点 + 状态后缀（"喘气疲惫的姿态" / "尖耳直立"），不要重新描述外貌

## 一条片子里换画风

按情绪分段换，例如前半暖调绘本风（引入/回忆），后半冷调（压抑/内省）。
但**一个段落内不换**，否则观众会觉得穿帮。

## 提示词里的"防翻车"短语

```
画面中只有一个主体；整张画面只描绘这一个角色，没有第二个人，没有分身，没有重影
角色从头到脚完整可见，任何部位不被画面边缘截断
无文字，无Logo，无水印，无边框，无白边，无黑边，无相框
```
