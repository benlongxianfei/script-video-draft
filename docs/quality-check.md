# 质量验收：生成模型不会一次就给你想要的

这份文档解决的是"怎么发现问题"，不是"怎么保证不出问题"。

## 一、静帧先过，再进视频

图生视频会**固化并放大**生图里的问题。所以：静帧不合格，不要进下一步。

每张图检查四件事：

| 检查项 | 看什么 |
|---|---|
| 主体数量 | 有几个头？几只翅膀？几条腿？有没有分身/重影 |
| 完整性 | 身体是否被画面边缘裁切、被遮挡 |
| 物种/身份一致 | 前后镜头里是同一只动物/同一个人吗（锚点有没有漂移） |
| 画风一致 | 线条密度、色调、材质是否同一条片子 |

自动化做法：用视觉模型批量问结构化问题，例如

```
请只回答 JSON：{"主体数量": n, "是否完整": true/false, "是否有重影": true/false, "问题": "一句话"}
```

注意两个误报来源：

- **多角色镜头**是设计需要，模型会误报"同一角色分身" → 把"本镜应为 N 个角色"写进问题里复核
- 视觉模型对同一张图会自相矛盾 → 疑似项必须二次复核

送检前先把图压到 ~768px / 40KB，几 MB 的图会连接重置。

## 二、成片必须抽帧

静帧正常 ≠ 视频正常。运动帧照样会画出双头双身。

对**草稿实际引用的**每段视频抽三帧：

```bash
ffmpeg -ss 0.8 -i video.mp4 -frames:v 1 -q:v 4 f1.jpg
ffmpeg -ss 2.5 -i video.mp4 -frames:v 1 -q:v 4 f2.jpg
ffmpeg -ss 4.2 -i video.mp4 -frames:v 1 -q:v 4 f3.jpg
```

0.8s 与 4.2s 覆盖开头与结尾的运动帧，这是最容易崩的两个位置。

## 三、降低失败率的提示词写法

1. **先锁主体，再写动作**：每镜只设一个主主体、一个主要动作、一个镜头运动
2. **物种写到级**："喜鹊"而不是"鸟"；必要时加"不是鸡、不是家禽"
3. **多角色逐个点名**：写清"画面中共 N 个角色"，每个角色单独加"单个、独立、无分身、无重影"
4. **降低提示词耦合**：不要同一镜同时要求多个动作、复杂交互、极端视角、大量道具
5. **动作默认低幅度**：轻微呼吸、眨眼、羽毛微动、慢推；避免大幅转身、快速扑翼
6. **完整可见**："角色从头到脚完整可见，任何部位不被画面边缘截断，不被其他物体遮挡"

## 四、抽帧映射必须按草稿实际素材

按"段号"去抽"镜头号"的视频会抽错素材，造成漏检。
正确做法：先拿到 `SEG_MATERIAL = {段号: 素材绝对路径}`，再按这个映射抽帧。

## 五、单镜重做链路（不要重跑全片）

```
改提示词（加单主体约束）→ 重新生图 → 静帧验收 → 图生视频 → 抽帧验收
→ OVERRIDE 替换该段素材 → 只重建这一段 clip → 重新校验三轨
```

## 六、封面

封面是独立交付物：**AI 只出无文字底图，标题在本地排版**。

- 底图提示词明确："无文字、无Logo、无AI标识、无边框、无白边、无相框"
- 尺寸：横版 1920×1080 / 竖版 1080×1920
- 文字压在画面上，避免遮挡主体关键部位
- 输出新版本号（v2 / v3），不覆盖旧封面
