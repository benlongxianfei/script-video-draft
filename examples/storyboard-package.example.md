# 分镜包示例（4 镜，可被 batch_generate.mjs 直接解析）

> 硬约束：`## G.` 与 `## H.` 的镜头数必须相等。
> 每镜 40 字左右；一个主体、一个动作、一个镜头运动。

## H. 每镜头图生视频卡

### 镜头1 图生视频卡
动作设计：手指轻微收紧，肩膀缓慢下沉
镜头运动：慢推
动作强度：低幅度
严格禁止：不改变外观、场景、文字；不增加人物

### 镜头2 图生视频卡
动作设计：眼皮缓慢眨动，胸口起伏
镜头运动：固定机位轻微推近
动作强度：低幅度
严格禁止：不改变外观、场景、文字；不增加人物

### 镜头3 图生视频卡
动作设计：门缓慢向内打开一条缝
镜头运动：慢推
动作强度：低幅度
严格禁止：不改变外观、场景、文字；不增加人物

### 镜头4 图生视频卡
动作设计：光影轻微晃动
镜头运动：极慢横移
动作强度：极低幅度
严格禁止：不改变场景、不出现人物、不加文字
